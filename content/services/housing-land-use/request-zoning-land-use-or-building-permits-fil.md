# Request ng Zoning, Land Use, o Building Permits — Lungsod ng San Pablo

Kumpletong gabay sa pagkuha ng zoning clearance, land-use approval, building permit, at occupancy permit sa San Pablo.

## Ano ito

Para sa **konstruksyon, renovation, occupancy, business location clearance, o land-use**, mag-coordinate sa angkop na city office. Kasama ang permits:

- **Locational / Zoning Clearance** — Tinitiyak ang land use compliance
- **Building Permit** — Pahintulot mag-construct o mag-renovate
- **Occupancy Permit** — Clearance ng istraktura para sa paggamit
- **Demolition Permit** — Para sa pagsira ng istraktura
- **Fence Permit** — Para sa permanenteng bakod
- **Electrical / Mechanical / Plumbing Permits** — Para sa utility installation
- **Subdivision / Condominium Approval** — Para sa development projects

## Sino ang nangangailangan

- **Mga property owner** na nagtatayo o nag-rerenovate
- **Mga contractor at developer**
- **Mga business establishment** na lumilipat o nagko-construct
- **Subdivision developers**
- **Eskuwelahan, ospital, religious organization** na nagtatayo
- **Mga homeowner** na nagtatayo ng bakod, addition, extension
- **Industrial operations** na may land use need
- **Sinumang nagbabago ng property use** (residential to commercial)

## Kailan mag-apply

| Permit | Kailan |
|---|---|
| **Zoning / Locational Clearance** | Bago ang anumang construction/renovation |
| **Building Permit** | Bago magsimula |
| **Occupancy Permit** | Bago tirhan / buksan ang bagong istraktura |
| **Demolition Permit** | Bago sirain |
| **Renewal of permits** | Per validity (karaniwang taunang) |

> Mag-plano ng **30–60 araw** ng lead time, lalo na sa major projects.

## Saan mag-apply

| Permit | Opisina |
|---|---|
| **Zoning / Locational Clearance** | CPDO (City Planning and Development Office) |
| **Building Permit** | Office of the Building Official (OBO) |
| **Occupancy Permit** | OBO |
| **Demolition Permit** | OBO |
| **Fence Permit** | OBO |
| **Subdivision Approval** | CPDO + DHSUD |
| **Industrial / Special Use** | CPDO + DENR |
| **Forms hub** | [sanpablocity.gov.ph/forms](https://www.sanpablocity.gov.ph/forms) |

## Bakit kumuha ng permit

- **Legal compliance** — Nangangailangan ang National Building Code (PD 1096)
- **Safety standards** — Tinitiyak ng permits ang structural safety
- **Insurance protection** — Karamihan ng insurer ay nangangailangan
- **Property value** — Properly assessed ang naka-permit na istraktura
- **Iwas penalty** — Pagtatayo na walang permit = fines + demolition risk
- **Future transactions** — Kailangan ng permit history sa real estate sales
- **Disaster resilience** — Mas matatag ang code-compliant structures
- **Resale value** — Tinitingnan ng buyer at bangko ang permits

## Mga uri ng permit

### 📋 Zoning / Locational Clearance
Inilalabas ng **CPDO**
- I-verify ang compliance sa City Zoning Ordinance
- Kailangan bago mag-apply ng building / business permit
- Pinapatibay ang land use matches city plan

### 🏗️ Building Permit
Inilalabas ng **OBO**
- Authorization mag-construct o mag-renovate
- Kailangan para sa anumang bagong istraktura o major renovation
- Kasama ang electrical, mechanical, plumbing review
- Validity: **1 taon**, pwedeng i-extend

### 🏢 Occupancy Permit
Inilalabas ng **OBO** pagkatapos ng konstruksyon
- Kailangan bago tirhan / gamitin ang istraktura
- Pinapatibay na sumusunod ang konstruksyon sa approved plans
- Kailangan para sa business permit issuance

### 🔨 Demolition Permit
Inilalabas ng **OBO**
- Kailangan bago sirain ang istraktura
- Kasama ang safety, debris management plan
- Coordinate sa kapitbahay

### 🏘️ Special Use Permits
- **Subdivision approval** — CPDO + DHSUD
- **Industrial use** — CPDO + DENR
- **Heritage site modifications** — National Historical Commission

## Paano mag-apply

### Hakbang 1 — Tukuyin kung anong permit ang kailangan
- **Bagong konstruksyon** → Zoning + Building + Occupancy
- **Renovation / addition** → Zoning + Building Permit
- **Bakod lang** → Fence Permit
- **Demolition** → Demolition Permit
- **Pagbabago ng business location** → Zoning + Locational Clearance

### Hakbang 2 — Ihanda ang mga dokumento
| Dokumento | Layunin |
|---|---|
| **Valid ID** | Identity verification |
| **Lot title** | Proof of ownership |
| **Tax declaration** | Updated tax record |
| **Lease contract** | Kung umuupa (may pahintulot ng may-ari) |
| **Authorization documents** | Kung representative (SPA) |
| **Location plan / vicinity map** | Site identification |
| **Building plans** | Architectural, structural, electrical, mechanical, plumbing |
| **Project description** | Buod ng gagawin |
| **Barangay clearance** | Local endorsement |
| **Business details** | Para sa business location clearance |

### Hakbang 3 — Kumuha muna ng Zoning / Locational Clearance
- Bumisita sa **CPDO** sa City Hall
- I-submit ang aplikasyon na may dokumento
- Maghintay ng **review at inspection**
- Tumanggap ng **Locational Clearance**

### Hakbang 4 — Mag-apply ng Building Permit
- Bumisita sa **OBO** sa City Hall
- I-submit ang Locational Clearance + Building Permit application
- I-submit ang signed-and-sealed plans (architect / engineer)
- Magbayad ng assessed fees sa **City Treasurer's Office**
- Maghintay ng permit issuance

### Hakbang 5 — Mag-construct ayon sa approved plans
- Magsimula ng konstruksyon
- **Sundin ang approved plans** nang mahigpit
- **Itago ang permits** sa site
- **Payagan ang inspection** ng OBO

### Hakbang 6 — Kumuha ng Occupancy Permit (pagkatapos)
- Mag-apply ng Occupancy Permit
- I-submit ang **as-built plans** kung may pagbabago
- Pasahan ang **final inspection** ng OBO
- Tumanggap ng Occupancy Permit
- Kailangan para sa **business permit / utility connections**

### Hakbang 7 — Mag-maintain ng permits
- **Renew ang expired permits** bago mag-expire
- **I-update** kung may further changes
- **Itago ang records** para sa property transactions

## Karaniwang requirements

- **Valid ID**
- **Lot title, tax declaration, lease, o authorization** documents
- **Location plan, sketch, o vicinity map**
- **Building plans** o project description (signed-and-sealed)
- **Barangay clearance** o endorsement
- **Business details** para sa location clearance
- **Updated real property tax payments**
- **Litrato** ng existing site

## Mahahalagang paalala

- **Palaging kumuha ng permits bago ang konstruksyon** — mahirap at magastos ang retroactive permits
- **Gumamit ng licensed architects / engineers** — kailangan para sa plan signing
- **Itago ang permits sa site** sa konstruksyon
- **Payagan ang OBO inspections** sa construction phases
- **Binubuo pa ang Forms hub** — direktang bumisita sa opisina
- **Sumunod sa Zoning Ordinance** — kailangan ng amendment para sa major land use changes
- **Magbayad lamang sa City Treasurer's Office** — huwag sa fixer
